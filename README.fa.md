## ✨ این چیست؟

‏**ktOperator** یک CLI امن و چند‌پرووایدری است که هوش مصنوعی را به یک «عامل سیستم‌عاملی» واقعی تبدیل می‌کند. تسک را به زبان طبیعی می‌گویید — «این پروژه را تحلیل کن»، «تست‌ها را اجرا کن و خرابی‌ها را خلاصه کن» — و عامل در **فضای کاری که خودتان صراحتاً مجاز کرده‌اید** برنامه می‌ریزد، فایل می‌خواند و می‌نویسد و دستور اجرا می‌کند؛ اما **هر قدم حساس از فیلتر یک موتور امنیتی کاملاً مستقل از مدل** رد می‌شود.

‏تفاوتش با «ابزارهای چت» اینجاست: اینجا هوش مصنوعی فقط *پیشنهاد* می‌دهد و سیستم شما *اجازه* می‌دهد یا رد می‌کند. هیچ کلیدی لو نمی‌رود، هیچ دستوری بیرون از ‏sandbox اجرا نمی‌شود، و هر تغییر مخرب از شما اجازه می‌خواهد و نسخهٔ بازگشت دارد.

## 🚀 نصب در ۱۰ ثانیه

```bash
npm i ktOperator
```

‏و همین! حالا فقط اجرا کنید:

```bash
ktoperator
```

‏**همان یک دستور کافی است؛ هیچ فرمان جداگانه‌ای برای setup وجود ندارد.** کنسول تعاملی خودش همه‌چیز را قدم‌به‌قدم جلو می‌برد:

```

╰──────────────────────────────────────────────╯

1️⃣  انتخاب پرووایدر ← OpenRouter · OpenAI · Anthropic · Google · Ollama
```

## 💬 داخل چت‌باکس چه خبر است؟

‏هر متنی بنویسید، برای عامل ارسال می‌شود. این دستورات اسلش هم همیشه در دسترس است:

| دستور | کار |
|---|---|
| ‏`/help` | راهنمای داخل کنسول |
| ‏`/provider` | فهرست پروفایل‌ها · ‏`/provider use <id>` · ‏`/provider add` |
| ‏`/model` | مدل فعلی · ‏`/model use <id>` · ‏`/model reload` |
| ‏`/workspace [path]` | نمایش یا تغییر مجوز فضای کاری |
| ‏`/sandbox` | وضعیت بک‌اندهای ایزولاسیون |
| ‏`/clear` | پاک‌کردن کانتکست گفتگو |
| ‏`/exit` | خروج (یا دو بار ‏Ctrl+C) |

## 🧰 برای اسکریپت و اتوماسیون

```bash
operator run "این پروژه را تحلیل کن و معماری‌اش را توضیح بده"
operator plan "تست‌ها را اجرا کن و خرابی‌ها را خلاصه کن"   # فقط برنامه، بدون اجرا
operator doctor                                             # تشخیص سلامت محیط
operator sandbox status                                     # وضعیت sandbox
operator provider add --id openrouter --type openrouter --model <id> --default
```

‏پرچم‌های سراسری: ‏`--json` برای خروجی ماشین‌خوان، ‏`--no-color`، ‏`--dry-run`، ‏`--yes read|write|all`، ‏`--max-steps`.

## 🔌 پرووایدرهای پشتیبانی‌شده

| پرووایدر | نکته |
|---|---|
| ‏**OpenRouter** | پرووایدر درجهٔ یک: کشف مدل، تشخیص قابلیت، گزارش هزینه/توکن |
| ‏**OpenAI** | کلید از متغیر ‏`OPENAI_API_KEY` یا استور محافظت‌شده |
| ‏**Anthropic Claude** | کلید از ‏`ANTHROPIC_API_KEY` |
| ‏**Google Gemini** | کلید از ‏`GOOGLE_API_KEY` |
| ‏**OpenAI-compatible** | هر اندپوینت سازگار با نشانی دلخواه |
| ‏**Ollama** | محلی و آفلاین — بدون نیاز به کلید |

‏نرمال‌سازی خطاها — احراز هویت، سقف اعتبار، ‏rate-limit به‌همراه ‏`Retry-After` — برای همهٔ پرووایدرها یکدست است.

## 🛡️ مدل امنیتی (خلاصهٔ صادقانه)

‏**اصل راهنما: هوش مصنوعی هرگز خودش را تأیید نمی‌کند.**

- 🔐 **موتور تأیید چهارسطحی مستقل** — خواندن، نوشتن، اجرای دستور و عملیات مخرب؛ هر کدام سیاست و آستانهٔ مخصوص خود را دارند.
- 📦 **اجباری و fail-closed بودن ‏sandbox** — اجرای دستور فقط داخل کانتینر ‏Docker با فایل‌سیستم فقط‌خواندنی، ‏drop شدن همهٔ ‏capabilityها، شبکهٔ غیرفعالِ پیش‌فرض و سقف حافظه/پردازه. اگر ‏sandbox در دسترس نباشد، اجرا **رد** می‌شود؛ بی‌سروصدا تنزل پیدا نمی‌کند.
- 🧱 **مرز فضای کاری با ‏realpath** — هر مسیر، حتی ‏symlinkها، به فرم کانونیکال حل می‌شود؛ خروج از دایرکتوری مجاز ممکن نیست.
- 🧼 **دفاع تزریق دستور** — خروجی ابزارها به‌عنوان «دادهٔ غیرقابل‌اعتماد» علامت می‌خورد، نه دستور جدید برای عامل.
- 🗝️ **صفر نشت کلید** — کلیدها فقط در استور ‏`chmod 600` یا متغیرهای محیطی؛ هرگز در لاگ، خروجی ‏`config show` یا هیچ‌جای دیگری جز اندپوینت خودِ پرووایدر.
- 📜 **نمایش ‏diff قبل از نوشتن، بکاپ خودکار و ‏rollback** — هر تغییر مخرب قابل پیش‌نمایش و قابل برگشت است.
- 🧾 **حسابرسی کامل** — نشست‌ها و رویدادهای امنیتی در ‏audit log محلی ثبت می‌شوند.
- 🌐 **ضد ‏SSRF** — اندپوینت‌های سفارشی فقط ‏HTTPS، بدون دنبال‌کردن ریدایرکت؛ آدرس‌های خصوصی فقط با پروفایل ‏`trustedLocal`.

‏مستندات کامل: [معماری](docs/architecture.md) · [امنیت](docs/security.md) · [مجوزها](docs/permissions.md) · [سندباکس](docs/sandbox.md)

## ⚖️ محدودیت‌هایی که صادقانه می‌گوییم

- ‏بدون ‏Docker (یا فعال‌کردن صریح ‏fallback) اجرای دستور رد می‌شود؛ تحلیل و برنامه‌ریزی همچنان کار می‌کند.
- ‏امنیت ‏sandbox به‌اندازهٔ کانتینر ران‌تایم شماست و جایگزین ماشین مجازی نیست.
- ‏عامل فقط در حد فضای کاری مجازشده و سیاست‌های شما قدرتمند است — بیشتر نه.
